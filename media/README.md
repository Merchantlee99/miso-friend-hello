# 사진·동영상 정리본

사이트 가이드와 홍보에 쓰는 사진 및 기존 공개 영상을 목적별로 정리했습니다. `manifest.csv`에서 파일명, 크기, SHA-256 해시를 확인할 수 있습니다.

- `01_당근_공고_게시`: 당근 공고 작성 안내
- `02_게시글_링크_담당자_전달`: 게시글 링크 전달 안내
- `03_지원자_확인과_채팅`: 지원자 확인 및 채팅 안내
- `04_외국인_비자_확인`: 비자 확인 안내
- `05_미소_초대링크_복사`: 초대링크 복사 안내
- `06_기존_블로그와_맘카페`: 이전 채널 안내
- `07_홈화면과_홍보_이미지`: 홈과 홍보 이미지

`01_현재_사이트_사진`은 현재 가이드에 쓰는 편집본입니다. `04_이전버전_사진`과 `05_홍보와_이전안내_이미지`에는 과거 문구가 포함될 수 있습니다.
