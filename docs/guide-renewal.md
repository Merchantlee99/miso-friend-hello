데이터는 시트의 정적 스냅샷이다. 원본 시트를 수정하거나 실시간 동기화하지 않는다. 시트 수정 사항을 적용하려면 데이터 파일을 갱신하고 배포해야 한다.

Fisher–Yates로 개인 브라우저의 순서를 섞고, 한 바퀴 안에서 반복하지 않는다. 마지막 다음에는 다시 섞으며 직전 공고는 연속으로 나오지 않는다. localStorage에 순서·위치를 보관한다. 안내 단계와 선택 탭은 sessionStorage에 보관한다. 브라우저 저장이 제한되면 현재 페이지 안에서 동작한다. 여러 사용자 사이의 공고 배정 중복은 막지 않는다.
